# agywe · Antigravity 壁纸插件

> [!WARNING]
> **非官方插件，与 Google、Antigravity 团队、Wallpaper Engine 均无关联。**
> 它会改动 Antigravity 安装目录里的 `resources\app.asar`，可能违反 Antigravity 的使用条款（见下面的[账号风险](#账号风险装之前请看)）；Antigravity 更新后也可能失效。安装前会自动备份原版程序包，随时可以用 `uninstall.cmd` 还原。使用风险自负。

当前版本：**v0.11.2** · 只在 Windows 上的 Antigravity 2.34.0 测试过 · 更新记录见 [CHANGELOG.md](CHANGELOG.md)

把本机 Wallpaper Engine 的壁纸铺到 **Antigravity 桌面 App**（2.x Agent 版）界面后面。
仿照 dsh-wallpaper-engine 的思路实现，场景壁纸用 WebWallGL（MIT）实时渲染。

## 账号风险，装之前请看

Google 的服务条款字面上不允许修改它的软件，装这个插件严格来说就违反了条款。Antigravity 的附加条款写明，违约可能导致 Antigravity 和 Gemini CLI 账号被暂停或终止。

目前公开的封号案例，基本都是用第三方工具借 Antigravity 的登录去调用模型、共享或转售额度。只改界面外观的插件（包括其他汉化、主题补丁）还没见到被封的公开案例，但 Google 怎么执行由它决定，**不保证零风险**。

这个插件做什么、不做什么：

- 只改你本机 Antigravity 的界面显示（壁纸、毛玻璃、汉化、挂件、桌宠、小组件）。
- 不读取、不保存、不转发你的登录信息，不替你自动发消息，不调用模型，不碰额度。
- 唯一会问 Google 的是用量卡片里的「额度」：调用的是 Antigravity 界面自己查额度的同一个函数（跟你打开模型选择看额度一样），默认每 5 分钟一次，在「小组件」里可以改成只在展开卡片时查，或者完全不查。
- 安装前会备份原版程序包，`uninstall.cmd` 可以逐字节还原。

工作账号、或者账号对你很重要的话，建议别装。

## 安装

1. 点本页上方的 **Code → Download ZIP** 下载，解压到 `%LOCALAPPDATA%\Programs\agywe-wallpaper`（文件夹名必须是这个：自动重装和诊断日志认的是这个位置）。解压后这个文件夹里直接就是 `install.cmd`，不要多套一层。
2. **完全退出 Antigravity**（右下角托盘图标 → 退出）。
3. 双击 `install.cmd`。
   - 不需要另外装 Node.js，安装器借用 Antigravity.exe 自己运行。
   - 会先把原版程序包备份成 `resources\app.asar.agywe-backup`。
   - 如果 Antigravity 的代码结构对不上，安装器**什么都不改**，直接退出。
4. 打开 Antigravity，点窗口顶部垂下来的挂件玩偶（或者往下拉它的绳子，或按 `Ctrl+Alt+W`）打开设置，在「壁纸库」里点一张壁纸。

## 卸载 / 出问题怎么办

| 情况 | 做法 |
|---|---|
| 不想用了 | 退出 Antigravity → 双击 `uninstall.cmd`（还原后和原版逐字节一致） |
| 卸载报错 / 打不开 | 退出 Antigravity → 双击 `restore-backup.cmd`（用整包备份覆盖） |
| Antigravity 自动更新后壁纸没了 | 一般会自动装回（看 `autofix.log`）；没装回的话退出后重新双击 `install.cmd` |
| 只想暂时关掉 | 设置面板右上角「启用」开关 |
| 查看状态 | 双击 `status.cmd` |
| Antigravity 更新了，想先确认还能不能装 | 双击 `test.cmd`（只读，什么都不改；结果在 `test\smoke-last.log`） |
| 连续两次没能正常启动 | 插件会自动进入安全模式（左下角有提示和「恢复」按钮）；「关于」页可以导出诊断报告 |

安装器支持参数：`--force` 自动结束正在运行的 Antigravity；`--exe <路径>` 指定 Antigravity.exe 位置（也可以设环境变量 `AGYWE_EXE`）。

## 功能

- **壁纸类型**：Scene 场景（粒子、骨骼、SceneScript、鼠标视差）、Video 视频、Web 网页；自定义图片 / 视频。Application / Preset 类型不支持。
- **壁纸库**：自动从注册表和 `libraryfolders.vdf` 找 Steam 库里的创意工坊壁纸（`workshop\content\431960`）、`myprojects`、`defaultprojects`；可以手动添加目录。支持搜索、类型筛选、收藏、隐藏。
- **场景失败时自动降级**：用壁纸自带的预览图顶上。
- **壁纸配置**：Wallpaper Engine 里每张壁纸自己的「属性」（滑块、开关、下拉、颜色、文字），按壁纸分别保存，场景 / 网页壁纸实时生效；支持属性的显示条件。还有暂停 / 继续、清除当前壁纸。
- **外观**：界面毛玻璃（直接写进元素内联样式，Antigravity 自己的 !important 样式也压不住；自动识别大块面板、顶部/底部细长条和输入栏外壳，不依赖 Antigravity 的类名；oklch 等新颜色写法也能识别）、面板不透明度、模糊、描边、统一色调、界面字体、压暗、文字阴影、适配方式。
- **手动点选毛玻璃区域**：自动识别漏掉或多处理的地方，在「外观」里点「点选界面区域」，直接在界面上点那块加上 / 去掉。
- **挂件玩偶**：从窗口顶部垂下来，会轻轻晃；点一下或往下拉绳子打开设置，左右拖动换位置；角色图片可以换成自己的桌宠：选图片文件（支持 GIF / APNG / WebP 动图，会自动打开正在运行的桌宠程序的文件夹），或者桌宠画在窗口里的话直接在界面上点选；大小、绳长可调；agent 运行时晃得更快。
- **播放**：帧率上限、渲染分辨率、粒子 / 后处理质量、音量、鼠标交互、失焦暂停、是否运行壁纸脚本。窗口最小化或被完全遮住时自动暂停。
- **系统联动**：音乐可视化壁纸跟着电脑正在播放的声音动（Windows 系统声音回环，只算频谱，不录音、不录麦克风）；「正在播放」把系统媒体的歌名、歌手、进度、封面传给支持的壁纸，壁纸里的播放 / 暂停 / 切歌按钮也能用。
- **气泡 / 卡片毛玻璃**：对话气泡、按钮这类小块也会变成半透明，有单独的最低不透明度，原本的实色描边会改成半透明。
- **对话区背板**：对话 / 工作区整块垫一层可调的磨砂，字不会直接压在壁纸上；和底下同色的分组标题、置顶条不再单独成块；输入框上方的淡出遮罩不再被模糊成一条。
- **文字可读性**：文字描边自动和文字反色（深色字配白边），壁纸压暗 / 提亮自动跟随文字颜色。
- **特效**：点击特效（波纹 / 星光 / 花瓣 / 爱心）、鼠标拖尾（光带 / 彗星 / 星屑），可选颜色或彩虹色。
- **开屏动画**：打开 Antigravity 时，接在它自带的加载画面后面播一段开屏，等界面和壁纸都准备好再揭开。四种样式：挂件登场（桌宠顺着绳子掉下来，揭开时从它那里扩开一个圆）、壁纸揭幕（模糊的壁纸预览图 + 大时钟，揭开时变清晰接上动态壁纸）、极简（A 字一笔画出）、自定义视频 / 动图。问候语、称呼、每日一句可改；随时点一下或按 Esc 跳过，最长等待可调，可设每天只播一次。
- **自动切换**：按时间（比如 07:00 白天一张、19:00 夜晚一张）和按项目 / 对话绑定壁纸；优先级 对话 > 项目 > 时间 > 壁纸库里选的。
- **Agent 状态提示**：任务完成时挂件跳一下、冒「完成啦」气泡；需要你确认或出错时换颜色并一直提示到你点掉；最后一个 agent 头像和壁纸边缘跟着变色。文字可以自己改。
- **打字时专注**：在输入框打字时壁纸变暗、变模糊或暂停，停手几秒恢复。
- **自动重装**：Antigravity 自动更新后插件会被冲掉。插件会在它退出去装更新时启动一个独立的 PowerShell 守着，更新装完就自动装回（可选立刻重启，或等你下次退出）；开机时也会检查一次。卸载后自动关闭，不会再装回去。记录在插件文件夹的 `autofix.log`。
- **会话头像**：你的消息右边、agent 的回复左边各一个头像；agent 默认用挂件（桌宠）的图片，回复中会闪烁，长回复时吸顶；头像可以换图、改大小和形状。头像是盖在界面上的浮层，不改 Antigravity 自己的页面，也不挡鼠标。
- **切换动画与视差**：换壁纸 / 轮播时可选淡入淡出、缩放、模糊过渡、滑入，时长可调；视频、图片、网页壁纸可以开鼠标视差。
- **外观预设**：内置「通透 / 磨砂 / 夜读」三套；外观、特效、挂件可以整套导出成 .json 再导入。
- **自动轮播**：按间隔顺序 / 随机切换收藏或全部壁纸，交叉淡入。
- **Agent 联动**：有 agent 在运行时，壁纸边缘出现呼吸光（或变亮）。
- **内置浏览器**：Antigravity 内置浏览器的标签页区域会被自动"挖空"，壁纸不会盖住网页。
- **界面汉化（插件内置）**：把 Antigravity 界面上的按钮、菜单、设置页、提示换成中文，词表约 2500 条，从 Antigravity 自己的界面代码里整理出来；带数字的句子（「快捷键 Ctrl+K：打开对话选择器」「6 天 3 小时后重置」）也会翻。只换界面固定文字，对话内容、代码、输入框、编辑器、终端里的字都不动；不改程序文件，关掉就还原。没翻到的会记进诊断报告，也可以在「补充翻译」里每行写一条「英文 = 中文」。「外观」页。
- **浮层和弹窗单独调**：模型选择（含子菜单）、下拉菜单、右键菜单、提示气泡这类浮层，和设置页这类弹窗，各有自己的不透明度和模糊，不跟着面板一起变透明，后面的字不会透上来。「外观」页。
- **窗口按钮那一条**：右上角最小化 / 最大化 / 关闭那一条是系统画的，毛玻璃碰不到，可以设成透明，或者用底下的壁纸颜色去填。「外观」页。
- **输入框外圈**：原来那圈深色外框换成一条细的半透明线，深浅可调。「外观」页。
- **允许其他插件挂进界面**：猫猫桌宠这类插件要通过 Antigravity 的本机调试端口把自己挂进界面。打开这个开关后，插件在启动时直接打开这个端口（只监听 127.0.0.1、端口随机），不用再改快捷方式参数。新装默认关。「外观」页。
- **用量卡片**：上下文占了多少、缓存命中率、生成速度、首字延迟，每一轮的输入 / 输出 / 思考 token，这个对话和今天、本月的总数，以及当前模型额度还剩多少、多久重置。平时是一个小胶囊，双击展开。「小组件」页还有按天、按模型的统计。
- **内置桌宠**：站在窗口下边的动画小人，跟着 agent 换动作（干活、完成、要你确认、出错），拖动换位置，单击摸摸，双击展开用量卡片。不用调试端口、不用 Python。插件不带动画素材，只读你电脑上已有的（比如「星星猫娘」插件 antigravity-catgirl-pet 自带的那套），也可以换成自己准备的文件夹。「挂件」页。

## 工作原理

安装器重新打包 `resources\app.asar`：

- 新增 `dist/agywe/`：主进程钩子 `hook.js`、用量统计 `usage.js`（只读打开本机对话记录）、协议声明 `scheme.js`、壁纸页与设置页 `app/`、原文件备份 `orig/`。
- `main.js` 第一行后 `require("./agywe/hook.js")`；钩子注册 `agywe://` 协议，负责读壁纸文件（支持视频拖动的 Range 请求）、保存设置、弹出选择文件对话框。
- `customScheme.js` 的协议特权列表里加入 `agywe`（Electron 只允许注册一次）。
- `preload.js` 末尾追加：在界面最底层插入 `agywe://app/index.html` 壁纸 iframe、毛玻璃、设置按钮、鼠标转发、agent 计数转发。

壁纸文件只在本机读取，不会上传；工坊素材版权归原作者。设置保存在 Antigravity 用户数据目录下的 `agywe\config.json`。

## 已知限制

- 视频壁纸直接用 Chromium 播放，H.264 / VP9 / AV1 没问题；HEVC 等编码可能放不了（dsh-wallpaper-engine 那种 ffmpeg 转码本项目还没做）。
- 毛玻璃是自动识别的，个别面板可能没变透明或变得太透；用「面板不透明度」调整，或者关掉「界面毛玻璃」。
- 只针对 Antigravity 2.x 桌面 App 测试过结构（2.34.0、2.35.1）；VS Code 那种 Antigravity IDE 不适用。

## 隐私

壁纸、设置、日志都只在本机读写，插件不会联网上传任何东西。系统音频只在本机算成频谱，不录音；「正在播放」只读 Windows 的媒体信息。
- 用量卡片的上下文和 token 数读的是本机 `%USERPROFILE%\.gemini\antigravity\conversations` 里 Antigravity 自己存的对话记录，只从中取出每次调用的 token 数、模型名和用时，不解析对话内容，不联网、不上传；读过的部分缓存在 `%APPDATA%\Antigravity\agywe\usage-cache.json`。额度见上面「账号风险」。
- 「允许其他插件挂进界面」默认关。打开后 Antigravity 会开一个只有本机能连的调试端口（`127.0.0.1`、端口随机），给猫猫桌宠这类插件用；本机上的其他程序也能通过它控制 Antigravity，不用这类插件就别开。在「外观」里开关，重启 Antigravity 生效。
